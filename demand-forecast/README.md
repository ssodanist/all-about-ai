# 프랜차이즈 물류 수요예측 · 발주추천 엔진

가맹점(점포) × 품목별로 **일별 수요를 예측**하고, **안전재고·유통기한·박스입수까지 반영한 발주수량**을
엑셀로 뽑아주는 경량 프로그램입니다. 설치는 `pandas`, `numpy`, `openpyxl` 세 개뿐이며,
점포×품목 1만 개 조합 기준 약 1분 안에 끝납니다.

## 빠른 시작

```bash
pip install -r requirements.txt
python make_sample.py                 # 데모 데이터 생성 (카페 8개 점포 × 20개 품목, 18개월)
python forecast.py --data sample_data --out output
```

출력 예:
```
백테스트 WAPE(오차율): 엔진 44.8%  vs  지난주 같은요일 방식 61.3%  → 오차 27% 감소
예측 편향: -0.1% (양수=과대예측)
```

## 웹 페이지 (`output/dashboard.html`)

실행할 때마다 **서버 없이 브라우저로 바로 여는 발주 페이지**가 함께 만들어집니다. 파일 하나라 메일·사내 공유폴더로
돌려도 되고, 사내 웹서버에 올려도 됩니다.

- **현재고·입고예정을 입력하면 발주수량·금액이 즉시 다시 계산**됩니다(입력값은 그 브라우저에 저장).
- 서비스수준(A/B/C)을 바꿔 보면 발주금액이 얼마나 변하는지 바로 볼 수 있습니다.
- 상태 표시: **결품위험**(이번 발주가 오기 전에 떨어짐 → 긴급배송 검토), **폐기위험**(유통기한 내 소진 불가), 발주, 충분.
- 품목을 누르면 최근 8주 판매·결품일·공휴일과 21일 예측(80% 범위), 발주량 계산 근거가 나옵니다.
- **발주서 복사** 버튼 → 엑셀이나 발주 시스템에 그대로 붙여넣기.
- 예측 정확도(품목별, 기존 방식 대비)와 학습된 특수일 효과 탭 포함.

## 엑셀 (`output/수요예측_발주추천.xlsx`)

엑셀이 편하면 이 파일을 열어 같은 작업을 할 수 있습니다.

| 시트 | 내용 |
|---|---|
| 요약 | 총 발주금액·건수, 예측 오차율, 벤치마크 대비 개선율, 점포별 발주금액 |
| 발주추천 | **노란 칸(현재고·입고예정)만 입력하면 발주수량이 자동 계산됨.** 리드타임·서비스수준 등 파란 글씨는 수정 가능 |
| 일별예측 | 점포×품목 21일 예측 (공휴일 강조) |
| 예측정확도 | 품목별 백테스트 결과 – 어떤 품목을 믿을 수 있는지 판단 |
| 특수일효과 | 학습된 공휴일·연휴 전날(점포별), 프로모션(품목별) 효과 |
| 사용법·가정 | 모든 가정값과 모델 설명 |

시스템 연동용으로 `order_plan.csv`, `forecast_daily.csv`, `accuracy.csv` 도 함께 생성됩니다.

## 입력 데이터 (CSV, `--data` 폴더)

| 파일 | 필수 | 컬럼 |
|---|---|---|
| `sales.csv` | ✅ | `date, store, sku, qty` + 선택 `stockout`(1=결품), `promo`(1=행사) |
| `sku_master.csv` | 권장 | `sku, name, lead_time, review_period, case_pack, moq, shelf_life, unit_cost` |
| `inventory.csv` | 권장 | `store, sku, on_hand, on_order` (오늘 아침 기준 재고·입고예정) |
| `promo_plan.csv` | 선택 | `date, store, sku` – 앞으로 예정된 행사 (`store`가 `*`이면 전 점포) |
| `holidays.csv` | 선택 | `date, name` – 내장 공휴일(2024~2027) 외 임시공휴일·지역 행사 |

> `sales.csv` 는 **가맹점 발주량이 아닌 실제 판매(POS)량**이 가장 좋습니다. 가맹점 발주 데이터만 있다면
> 그것으로도 동작하지만, 점주들의 '불안 발주'까지 학습하게 됩니다.
> 결품 여부(`stockout`)를 꼭 넣어주세요 – 결품일 판매량은 수요보다 작게 찍혀 예측을 끌어내립니다.

## 어떻게 예측하나 (물류 실무 관점)

1. **결품 보정** – 결품일은 '수요'가 아니라 '잘린 판매량'이므로 학습에서 제외합니다.
   그대로 쓰면 *결품 → 낮은 예측 → 적은 발주 → 또 결품* 악순환이 생깁니다.
2. **요일 지수 + 계층 수축** – 점포마다 요일 패턴을 따로 학습하되, 판매량이 적은 품목은
   같은 품목의 전 점포 공통 패턴을 더 신뢰합니다(소량 품목의 들쭉날쭉 방지).
3. **특수일 효과 학습** – 공휴일·연휴 전날 효과는 **점포별**(오피스 상권은 급감, 몰은 급증),
   프로모션 효과는 **품목별**로 과거 데이터에서 추정합니다. 관측이 적으면 효과를 보수적으로 줄입니다.
4. **이상치 처리** – 단체주문 같은 일회성 급증은 MAD 기준으로 잘라 기준 수요를 오염시키지 않게 합니다.
5. **수요패턴 분류** – ADI/CV² (Syntetos-Boylan) 로 안정형/변동형/간헐형/불규칙형 분류.
6. **모델 자동선택** – 지수평활(2종), 감쇠추세 홀트, 28일 이동평균, Croston-SBA(간헐형 전용),
   앙상블 중 **최근 8주를 매일 실제로 예측해 본 결과(백테스트)** 가 가장 좋은 모델을 시계열마다 고릅니다.
   평가 기준은 `MAE + |편향|` – 간헐 품목에서 "0개 예측"이 뽑히는 함정을 막습니다.
7. **안전재고** – 수요 표준편차가 아니라 **보호기간(리드타임+발주주기) 동안의 누적 예측오차**로
   계산합니다. 예측이 정확한 품목은 재고를 줄이고, 불확실한 품목만 두껍게 가져갑니다.
8. **발주량** – `목표재고 = 보호기간 예측수요 + 안전재고` (단, **유통기한 내 소진 가능량을 상한**),
   `발주량 = 목표재고 − 현재고 − 입고예정` → 박스입수 단위 올림, MOQ 적용.
   서비스수준은 ABC 등급별(A 98% / B 95% / C 90%)로 차등.

## 비용이 줄어드는 지점

| 매일 발생하던 비용 | 엔진이 막는 방식 |
|---|---|
| 신선품 폐기 | 유통기한 상한, 과대편향 모니터링(요약 시트 '예측 편향') |
| 결품·긴급배송 | 결품 보정 학습, 오차 기반 안전재고, 연휴·행사 사전 반영 |
| 과잉재고·창고 공간 | 품목별 서비스수준 차등(C등급은 얇게), 정확한 품목의 안전재고 축소 |
| 담당자 수작업 | 현재고만 입력하면 박스 단위 발주량까지 자동 산출 |

## 옵션

```bash
python forecast.py --data 내데이터 --out 결과 --horizon 28 --backtest-days 84 --sl-a 0.99 --sl-b 0.96 --sl-c 0.9
```

## 운영 팁

- **매일 돌리세요.** 어제 판매가 들어오면 모델 상태가 갱신됩니다(크론/작업 스케줄러에 등록).
- **예측정확도 시트에서 WAPE가 높은 품목**은 판매 이력이 짧거나 진짜 무작위인 품목입니다. 이런 품목은
  발주주기를 늘리거나 MOQ·박스입수 조정을 협의하는 편이 예측 개선보다 효과적입니다.
- 신규 점포는 비슷한 상권 점포의 데이터를 복사해 초기값으로 쓰는 것을 권장합니다.
- 연 단위 계절성(여름 음료 등)은 수준 추적으로 따라가며, 2년 이상 이력이 쌓이면 전년 동기 지수를 추가하는 것을
  다음 단계로 권장합니다.
