| 조건 | 정의 |
|---|---|
| 무자본 | 재고·설비·인허가 자본 없이 1인 + AI 도구 + 공공데이터/카톡/노코드로 2주 안에 MVP |

## 1. 선택한 사고법 2개와 이유

1. **④ 문제 재정의 알고리즘** `PR = P₀ × T(θ) × S(φ) × M(ψ)`
   미DX 섹터는 "디지털화가 안 됐다"가 문제가 아니라, **아무도 그 문제를 돈이 되는 형태로 정의하지 않았다**가 문제다. 관점 회전(θ), 범위 조정(φ), 메타 이동(ψ)으로 문제를 다시 정의한다.
2. **③ 창의적 연결 매트릭스** `CC = |A∩B| + |A⊕B| + f(A→B)`
   "세상에 없는" 서비스는 대부분 **이미 검증된 다른 산업의 메커니즘(A)을 낙후 섹터(B)로 전이**한 것이다. f(A→B)가 핵심.

> 평가: 혁신적 솔루션 공식(⑤)을 간이로 적용 — `IS = N × F × V / R` (각 1~5점, N 참신성 · F 무자본 실현성 · V 엑싯 가치 · R 리스크)

## 2. 아이디어 12선

### #1. 품앗이 원장 — 경조사 상호부조 장부
- **P₀** 장례/결혼 후 방명록·부의금 정리가 수기
- **재정의 (ψ+1)** 경조사는 3일짜리 이벤트가 아니라 **평생 이어지는 비공식 상호부채(채권·채무) 시스템**이다
- **연결** 복식부기 원장 × 한국 품앗이 문화 → "누가 나에게 얼마를 했고, 내가 누구에게 갚아야 하나"
- **MVP** 방명록·부의금 봉투 사진 OCR → 자동 원장 → 답례 문자 → 상대 경조사 발생 시 "갚을 차례" 알림
- **수익** 프리미엄 장부, 답례품 커머스 수수료, 경조사 송금 연동
- **엑싯 후보** 간편송금 핀테크, 상조회사, 웨딩/장례 플랫폼 — "한국인의 관계 그래프 + 송금 트리거" 데이터
- **리스크** 개인정보(제3자 이름·금액) 처리 설계 필요
- **IS** N5 · F5 · V3 / R2 = **37.5**

### #2. 디지털 유산 정리 대행
- **P₀** 유품정리는 물건 중심, 고인의 계정·구독·포인트·클라우드·가상자산은 방치
- **재정의 (도메인 전환)** 유품 = 물건 → **유품 = 데이터와 자동결제**
- **연결** 기업 IT 오프보딩(퇴사자 계정 회수) × 상속
- **MVP** 상속인 체크리스트 웹 + 서비스별 해지/이관 절차 DB + 카드 명세서 분석으로 정기결제 탐지
- **수익** 건당 15~30만원, 상조·보험 B2B 번들
- **엑싯 후보** 상조회사, 생명보험사, 유품정리 업체
- **IS** N5 · F4 · V3 / R2 = **30**

### #3. 입주민 편 관리비 감사 AI
- **P₀** 아파트 관리 SaaS는 관리사무소(공급자) 편
- **재정의 (θ=180°)** 관리사무소 효율화 → **입주민·입대의의 감시/감사 도구**
- **연결** 상장사 회계감사(이상거래 탐지) × 공동주택 관리비
- **MVP** 공동주택관리정보시스템(K-apt) 공개 관리비 데이터로 단지별 "동급 단지 대비 이상 항목" 무료 리포트 → 입대의·동대표 유료 구독
- **수익** 단지 구독, 관리업체 교체 입찰 중개 수수료
- **엑싯 후보** 아파트 관리 플랫폼, 부동산 정보 플랫폼(단지 품질 지표로 활용)
- **IS** N4 · F5 · V4 / R2 = **40**

### #4. 농산물 출하 라우터 — 도매시장 간 차익
- **P₀** 농민은 "얼마에 팔릴지" 모른 채 습관적으로 한 시장에 출하
- **재정의 (φ×10)** 한 농가의 가격 문제 → **전국 공영도매시장 간 가격 차이(차익거래) 문제**
- **연결** 증권 스마트 오더 라우팅(SOR) × 농산물 출하
- **MVP** 공개 경락가 데이터로 "내일 어느 시장에 보내면 운송비 빼고 얼마 더 받는가" 카톡 알림
- **수익** 작목반·산지유통인 구독, 출하 대행 수수료
- **엑싯 후보** 농업 플랫폼, 농협 계열 디지털 조직, 유통 대기업
- **IS** N4 · F4 · V4 / R3 = **21.3**

### #5. 중장비 유휴시간 거래소
- **P₀** 굴삭기·덤프 배차는 지역 중기 사무실 카톡방과 전화
- **재정의 (ψ+1)** 장비 임대 → **"놀고 있는 시간"이라는 소멸성 재고의 판매**
- **연결** 항공사 수익관리(Yield Management) × 건설기계
- **MVP** 지역 중기 카톡방 공지 파싱 봇 → 유휴 장비·시간 자동 정리 → 현장소장 매칭
- **엑싯 후보** 건설기계 제조사, 건설 테크 기업, 장비 렌탈사
- **IS** N4 · F3 · V5 / R3 = **20**

### #6. 하도급 원청 체불 리스크 스코어
- **P₀** 전문건설 하청은 원청 신용을 모르고 계약
- **재정의 (θ=180°)** 원청이 하청을 평가 → **하청이 원청을 평가**
- **연결** 개인 신용평가 × 건설 하도급
- **MVP** 공개 데이터(체불사업주 명단 공개, 행정처분, 건설업 등록 정보, 공시) 결합 → 원청 리스크 조회 리포트
- **엑싯 후보** 신용평가사, 건설 플랫폼, 보증기관 연계 사업자
- **리스크** 명예훼손 소지 → 공개 데이터만, 사실 기반 표기
- **IS** N5 · F4 · V4 / R3 = **26.7**

### #7. 외국인 근로자 체류·고용 컴플라이언스 양면 AI
- **P₀** 중소 제조·농가 사업주가 체류만료·고용허가 연장·보험을 놓침
- **재정의** 인력난 문제 → **놓치면 벌금인 마감일 관리 문제**
- **연결** 법인 컴플라이언스 캘린더 × 다국어 근로자 상담 챗봇 (양면: 사업주 대시보드 + 근로자 모국어 AI)
- **엑싯 후보** HR SaaS, 행정사 법인, 인력 송출·관리 업체
- **IS** N3 · F4 · V5 / R2 = **30**

### #8. 동네가게 마이크로 M&A 거래소
- **P₀** 학원·미용실·카페 양도양수는 권리금 감과 중개사 말에 의존
- **재정의 (ψ+2)** 점포 임대 거래 → **소기업 M&A(현금흐름 기반 가치평가)**
- **연결** 기업 M&A 실사·밸류에이션 × 동네 자영업
- **MVP** 학원 한 업종으로 시작: 원생 수·수강료·임대료 입력 → AI 가치평가 리포트 + 매물 리스트
- **수익** 리포트 판매, 성사 수수료
- **엑싯 후보** 상가/부동산 플랫폼, 프랜차이즈 본사, 소상공인 금융사
- **IS** N4 · F4 · V4 / R2 = **32**

### #9. 인테리어 공정 증빙 원장
- **P₀** 인테리어 분쟁의 원인은 "무엇을 어떻게 시공했는지 증거가 없음"
- **재정의** 업체 신뢰 문제 → **증빙 데이터 부재 문제**
- **연결** 차량 블랙박스 × 시공 공정
- **MVP** 시공팀이 사진만 찍으면 공정별 자동 정리 + 고객 공유 링크(업체 무료) → 이력 누적 시 하자보증 상품
- **엑싯 후보** 인테리어 플랫폼, 보증보험사
- **IS** N3 · F4 · V4 / R2 = **24**

### #10. 고물상 시세 인덱스 + 장부 AI
- **연결** 원자재 거래소 시세 공시 × 고물상 매입 장부
- **MVP** 지역 고물상 매입 단가 수집·공개 → 장부 AI로 무료 제공 → 재활용 원자재 지역 지수
- **엑싯 후보** 재활용·ESG 기업
- **IS** N4 · F3 · V3 / R3 = **12**

### #11. 가족 분묘 디지털 등기부
- **재정의** 벌초 대행 → **"우리 조상 묘가 어디 있는가"라는 위치 데이터 + 개장(이장) 수요**
- **MVP** 가족 단위 묘소 GPS·사진 등록 → 벌초·개장·화장 업체 연결
- **엑싯 후보** 상조회사, 장묘 업체
- **IS** N5 · F3 · V3 / R3 = **15**

### #12. 간병 일지 다국어 AI + 간병인 포터블 평판
- **연결** 플랫폼 노동자 평점 × 간병
- **MVP** 간병인이 모국어 음성으로 기록 → 보호자에게 한국어 리포트 → 누적 이력이 간병인의 이동 가능한 평판
- **엑싯 후보** 간병 매칭 플랫폼, 요양 체인, 보험사
- **IS** N3 · F3 · V4 / R3 = **12**

## 4. 전략가 메모 — "빠른 엑싯"의 현실

- 국내 소형 스타트업 M&A 시장은 얇다. 빠른 엑싯은 **매출 배수보다 "인수자가 직접 만들기 귀찮은 데이터/네트워크"** 로 결정된다.
- 따라서 각 아이디어는 **Day 1부터 인수 후보 3곳을 정하고, 그들의 KPI를 올려주는 데이터**를 쌓도록 설계해야 한다.
- 무자본의 핵심은 **공개 데이터 + 기존 카톡방/커뮤니티 기생 + AI 자동화**. 영업은 사람이, 운영은 AI가.
- "세상에 없는지"는 실행 전 경쟁 조사로 반드시 검증할 것 (Round 2 과제).
