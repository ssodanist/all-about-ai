# Round 2 — 동네가게 양도양수: 「바톤」 사업 설계 (목표: 기업가치 5억)

> 가칭 **바톤(Baton)** — 학원을 다음 원장에게 넘기는 바톤 터치.
> 사고법: ⑧ 복잡성 해결 매트릭스(거래를 하위 시스템으로 분해) × ⑥ 인사이트 증폭(Why 5회)

## 1. 경쟁 조사 결과 (Round 1 과제 이행)

| 플레이어 | 하는 일 | 빈 곳 |
|---|---|---|
| 권리머니(오아시스비즈니스) | AI 매출 추정 기반 **범용** 점포 권리금 조회 | 업종 범용 → 학원 특유의 가치 요인(원생 재원기간, 강사 의존도, 학령인구)을 반영하지 않음. 거래 이후는 없음 |
| 점포라인 | 점포 매물 중개, 중개수수료 무료 정책 | 매물 리스트 중심, 가치 근거·인수인계 없음 |
| 당근 부동산 | 학원 매물이 직거래로 올라옴 (권리금 0원, "아이들을 권리금으로 팔고 싶지 않다") | 직거래 → 계약서 불완전, 보증 주체 부재, 분쟁 |
| 비즈토스 | 이커머스 M&A, AI 실사 | 온라인 사업 한정 |

**결론:** "점포 권리금"은 경쟁이 있다. 비어 있는 곳은 **① 업종 특화(학원) ② 원생 유지에 연동된 권리금 ③ 인수 후 90일 인수인계(PMI)** 이다. 이 셋을 묶은 서비스는 찾지 못했다.

## 2. Why 5회 — 진짜 문제

1. 왜 학원 양도가 어려운가? → 가격 합의가 안 된다
2. 왜 합의가 안 되나? → 권리금의 대부분이 "원생"인데, 원생이 남을지 아무도 모른다
3. 왜 모르나? → 원생은 원장·강사를 따라 움직이고, 양도 사실을 알면 이탈한다
4. 왜 그 리스크를 아무도 안 지나? → 거래가 1회성 직거래라 보증 주체가 없다
5. 왜 보증 주체가 없나? → **거래 데이터(실제 유지율)가 쌓인 곳이 없어 리스크 가격을 매길 수 없다**

→ **바톤의 본질: "원생 유지율 데이터"를 쌓아 학원 권리금의 리스크를 가격으로 바꾸는 회사.** 이 데이터가 곧 엑싯 가치다.

## 3. 제품 — 하위 시스템 분해

| 하위 시스템 | 내용 | 무자본 구현 |
|---|---|---|
| S1 가치 진단 | 월순익 × 업종 배수(원장 의존도·재원기간·임대 잔여·운영연수 보정) | 웹 계산기 (프로토타입 완료) + LLM 리포트 |
| S2 매도자 발굴 | NEIS 전국학원·교습소 표준데이터(개설일, 휴원/폐원 상태)로 지역별 리스트 → 원장 카페·DM | 공공데이터 + 수작업 |
| S3 매수자 풀 | 독립 준비 중인 강사, 확장하려는 원장 | 강사 커뮤니티, 채용 사이트 |
| S4 **원생 연동 권리금** | 권리금을 70% 선지급 + 30%는 90일 후 원생 유지율에 따라 정산 (Earn-out) | 계약서 템플릿으로 시작. 돈은 직접 보관하지 않음 |
| S5 **90일 인수인계(PMI)** | 학부모 안내문, 원장 교체 상담 스크립트, 개인정보 이전 통지, 강사 잔류 계약, 주간 유지율 체크 | 템플릿 + 카톡 알림 자동화 |

## 4. 수익 모델과 5억 도달 경로

**가정 (실거래로 검증 필요):** 학원 평균 권리금 3,000~5,000만원.

| 수익원 | 단가 | Year 1 | Year 2 |
|---|---|---|---|
| 정밀 가치 진단 리포트 | 19만원 | 100건 = 0.19억 | 400건 = 0.76억 |
| 거래 성사 보수 (매도자, 권리금의 5%, 최소 150만원) | 평균 200만원 | 15건 = 0.3억 | 60건 = 1.2억 |
| 90일 인수인계 패키지 (매수자) | 49만원 | 10건 = 0.05억 | 50건 = 0.25억 |
| **합계** | | **약 0.54억** | **약 2.2억** |

**5억으로 가는 세 갈래 (병행)**
- **A. 매출 배수형:** 연 매출 2.2억 × 2~2.5배 = 4.4~5.5억. 2년차 말 도달.
- **B. 전략 인수형:** 학원 관리 SaaS·에듀테크·학원 프랜차이즈 본사 입장에서 바톤은 "전국 학원의 매도 의향 + 가치평가 + 유지율 데이터"를 가진 회사. 거래 100건, 등록 학원 1,000곳 수준이면 5억 협상 가능 구간.
- **C. 투자 유치형:** 6개월 내 거래 10건 + 월 반복 매출이 생기면 시드 라운드에서 기업가치 5억 이상은 현실적인 숫자.

> 전략가 의견: **A를 기본으로 두고 B를 목표로 설계**. B 후보 3곳을 정해 Month 3부터 데이터 제휴를 제안하면, 인수 대화가 자연스럽게 시작된다.

## 5. 실행 로드맵

| 기간 | 목표 | 핵심 지표 (통과 기준) |
|---|---|---|
| Week 1–2 | 지역 1곳 선정, NEIS 데이터로 학원 리스트, 원장 20명 인터뷰, 계산기 배포 | 진단 신청 30건, 매도 의향 원장 5명 |
| Month 1–3 | 컨시어지 거래 (사람이 다 함) | 거래 3건 성사, 평균 수수료 확인 |
| Month 4–9 | 리포트 자동화, 매물 페이지, PMI 템플릿, 인접 지역 확장 | 누적 거래 15건, 90일 원생 유지율 데이터 15개 |
| Month 10–18 | 교습소·음악·미술·태권도로 확장, 인수 후보와 제휴 | 연 매출 run-rate 2억, 인수 후보와 대화 개시 |
| Month 18–24 | 엑싯 또는 시드 | 기업가치 5억 이상 |

## 6. 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 상가 임대차 중개는 공인중개사 업무 | 권리금·영업양도 컨설팅만 직접, 임대차 부분은 제휴 공인중개사에 연결 (법률 자문으로 경계 확정 필요) |
| 원생 개인정보 이전 | 영업양도 시 개인정보 이전 통지 절차를 PMI 패키지에 포함 (법률 검토 필요) |
| 대금 보관 = 전자금융업 이슈 | 바톤은 돈을 보관하지 않음. 분할지급은 계약 구조로만, 필요 시 은행 에스크로 연계 |
| 거래 빈도가 낮음 (학원 하나당 평생 1~2번) | 매도 전 1~2년부터 "가치 올리기" 구독으로 관계 유지 |
| 경업금지 분쟁 | 계약서 템플릿에 경업금지 지역·기간 표준 조항 |
| 배수 가정이 틀릴 수 있음 | 첫 10건 실거래로 배수 재보정. 계산기는 "추정치"로 명시 |
